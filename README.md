# My AI Cafe — Prompt Library

A static site with 24 curated, task-organized AI prompts. Served via GitHub Pages at https://prompts.myaicafe.com.

- `index.html`: the library (6 categories, copy buttons, About, FTC disclosure)
- `style.css`, `script.js`: styling and the copy-to-clipboard buttons
- `404.html`: not-found page
- `CNAME`: custom domain

Static only: no forms, analytics, trackers, external scripts/fonts, or backend.

Deploy: push to `myaicafe/prompts`, enable Pages (branch `main`, root), and add a DNS CNAME `prompts` → `myaicafe.github.io`.
